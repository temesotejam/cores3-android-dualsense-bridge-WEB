M5Stack CoreS3 / ESP32-S3

Android DualSense Bridge

開発環境をインストールせず、USB接続したM5Stack CoreS3へブラウザからファームウェアを書き込みます。

書き込み前の確認

これはM5Stack CoreS3専用です。書き込みを行うと、CoreS3に現在入っているファームウェアは置き換えられます。

CoreS3へ書き込む

  1. CoreS3を通信可能なUSB Type-CケーブルでPCへ接続します。
  2. 下のボタンを押し、CoreS3のCOMポートを選択します。
  3. 画面の案内に従ってインストールします。

このブラウザはWeb Serialに対応していません。PC版ChromeまたはEdgeで開いてください。

安全なHTTPSページから開く必要があります。

ポートが表示されない場合は、USBケーブル、CoreS3の電源状態、USBドライバを確認してください。

書き込み後の使い方

  1. CoreS3がWi-Fiアクセスポイント CoreS3-Control を起動します。
  2. LG style3をそのWi-Fiへ接続します。
  3. Android版Chromeで http://192.168.4.1 を開きます。
  4. DualSenseをLG style3へBluetooth接続し、画面の「接続開始」を押します。
